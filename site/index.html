Questions

Où trouver ma clé API Aristote ?

Sur aristote.education/llm-access, après connexion avec ton compte universitaire (Université Paris-Saclay et universités associées). Elle commence par sk-. L'installateur la demande et la vérifie ; tu peux la changer plus tard dans pi avec /aristote key sk-….

Inutile de noter la liste des modèles envoyée par email : l'extension la récupère toute seule. Attention, « Régénérer la clé » sur la page d'Aristote invalide l'ancienne : il faudra alors refaire /aristote key.

Comment mettre à jour ?

Dans pi, tape /maj : l'extension se met à jour et se recharge en quelques secondes, sans quitter pi. pi te prévient tout seul au démarrage quand une nouvelle version est disponible. Relancer la commande d'installation marche aussi.

Et sous Windows ?

Utilise WSL (Ubuntu) et la commande ci-dessus. Une version PowerShell native viendra si le besoin se fait sentir.

Qu'est-ce qui est installé, et où ?
  • pi, via npm (dans ton Node.js, ou dans ~/.local/share/pi-aristote/node s'il a fallu en installer un) ;
  • l'extension dans ~/.pi/agent/extensions/aristote et le thème dans ~/.pi/agent/themes ;
  • ta clé dans ~/.pi/agent/auth.json (lisible par toi seul).

Pour tout désinstaller : rm -rf ~/.pi/agent/extensions/aristote, puis npm uninstall -g @earendil-works/pi-coding-agent si tu veux aussi retirer pi.

Je veux lire le code avant de l'exécuter

Très bonne idée : install.sh et le dépôt GitLab. Tu peux aussi télécharger l'extension seule : pi-aristote.tar.gz.
