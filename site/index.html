Mise à jour de la responsabilité

Depuis la 1.9.0, pi demande votre accord avant chaque commande qu'il veut lancer. Pour s'en passer : pi --yolo, ou /yolo dans pi (vous restez responsable de ce qu'il exécute). Depuis la 1.10.0, pi --yom ou /yom laisse passer l'inoffensif (lecture, téléchargements, tests) et ne demande que pour le sensible : rm, mv, git push, sudo…

Installe en une commande

Dans PowerShell. Première fois ? Installe d'abord WSL : wsl --install dans un PowerShell ouvert en administrateur, redémarre, et choisis ton nom d'utilisateur Linux dans la fenêtre Ubuntu qui s'ouvre. Ensuite, colle :

Ouvre un terminal, colle avec ⌘ V (ou Ctrl ⇧ V), appuie sur Entrée. C'est tout. Ensuite, pour mettre à jour : /maj dans pi.

Ensuite, pour travailler : tape wsl, puis pi dans ton dossier de code (tes disques Windows sont dans /mnt/c). Pour mettre à jour : /maj dans pi.

Questions

Où trouver ma clé API Aristote ?

Sur aristote.education/llm-access/, après connexion avec ton compte universitaire (Université Paris-Saclay et universités associées). Elle commence par sk-. L'installateur la demande et la vérifie ; tu peux la changer plus tard dans pi avec /aristote key sk-….

Inutile de noter la liste des modèles envoyée par email : l'extension la récupère toute seule. Attention, « Régénérer la clé » sur la page d'Aristote invalide l'ancienne : il faudra alors refaire /aristote key.

Comment mettre à jour ?

Dans pi, tape /maj : l'extension se met à jour et se recharge en quelques secondes, sans quitter pi. pi te prévient tout seul au démarrage quand une nouvelle version est disponible. Relancer la commande d'installation marche aussi.

Et sous Windows ?

Ça passe par WSL (un Linux intégré à Windows). Le site détecte Windows et affiche la bonne commande, à coller dans PowerShell ; si WSL n'est pas encore installé, commence par wsl --install et redémarre. Ensuite, tape wsl puis pi.

J'utilise déjà pi avec d'autres fournisseurs : rien ne casse ?

Aucun souci : l'installateur ne change ni ton fournisseur par défaut ni ta configuration sans te le demander (réponse par défaut : non), sauvegarde chaque fichier avant de le modifier dans ~/.pi/agent/backups/, et ne touche pas à un fichier qu'il ne sait pas lire. Les mises à jour (/maj) ne remplacent que l'extension.

Le modèle peut-il répondre dans une autre langue ?

Oui : par défaut, il répond dans la langue dans laquelle tu lui écris. Pour en imposer une, tape /langue en, /langue es… et /langue auto pour revenir au comportement par défaut.

Quelles commandes dans pi ?
  • /ultracode (ou Alt U) : le Lycée au complet ; /peripateticien, /euclide, /hephaistos, /socrate, /sappho : un disciple seul, suivi d'une mission ;
  • /langue : langue des réponses ; /aristote : état des modèles et de la clé ; /maj : mise à jour ; /gardefou off (ou on) : couper ou rétablir le garde-fou anti-boucle, actif par défaut ; /yolo (ou pi --yolo) : exécuter les commandes sans confirmation (pi demande d'abord si vous êtes sûrs : un moteur de F1 implique de savoir conduire) ; /yom (ou pi --yom) : l'inoffensif passe seul, le sensible demande votre accord ;
  • /clear : repartir de zéro ; /exit : quitter. Échap interrompt, Ctrl O déplie les comptes rendus, Ctrl L change de modèle.

Pas de commande pour le navigateur : demande simplement « cherche sur le web… ».

Qu'est-ce qui est installé, et où ?
  • pi, via npm (dans ton Node.js, ou dans ~/.local/share/pi-aristote/node s'il a fallu en installer un) ;
  • l'extension dans ~/.pi/agent/extensions/aristote et le thème dans ~/.pi/agent/themes ;
  • ta clé dans ~/.pi/agent/auth.json (lisible par toi seul) ;
  • au premier usage du navigateur, playwright-core et un profil de navigation dédié dans ~/.pi/agent/aristote-navigateur (ton navigateur habituel n'est pas touché).

Pour tout désinstaller : rm -rf ~/.pi/agent/extensions/aristote ~/.pi/agent/aristote-navigateur, puis npm uninstall -g @earendil-works/pi-coding-agent si tu veux aussi retirer pi.

Je veux lire le code avant de l'exécuter

Très bonne idée : tout est sur le dépôt GitLab du LISN, à commencer par install.sh. Tu peux aussi télécharger les fichiers tels que cette page les sert : l'installateur, install.sh, et l'extension seule, pi-aristote.tar.gz.
